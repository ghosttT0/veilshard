# Veilshard (隐纱之核) 宣传片分镜脚本

> **片名**：Veilshard — 让节点群自己照顾自己
> **时长**：100 秒（1'40"，落在 1–2min 区间）
> **画幅**：16:9 · 1920×1080 · 30fps（可另出 9:16 竖版）
> **投放场景**：GitHub README 置顶 / B 站 / X / Linux.do
> **目标观众**：自建 VPS、抗审查、自托管社群（有 Linux 基础，被一键脚本坑过的人）

## 〇、制作前提：没有 UI 怎么办

Veilshard 是纯 CLI 项目，本片不出现任何网页截图。视觉语言只有三层，全部可用代码确定性生成（Remotion / Canvas / SVG）：

1. **终端即 UI**：所有命令与输出按品牌视觉重绘（深色底、等宽字体、水晶青高亮），不是屏幕录制，而是逐字符打字机动画——清晰、锐利、节奏可控。终端内容必须逐字取自 README 真实命令与输出，不虚构功能。
2. **抽象动效叙事**：拓扑图生长、密钥碎片换位、密文流、黑洞陷阱——把看不见的"控制平面"画出来。这是 awesome-opus5.5-videos 里产品片的主流语法。
3. **品牌隐喻贯穿**：**Veil（纱）** = 半透明波动纱幕遮蔽流量；**Shard（核片）** = 水晶碎片聚合成盾。 logo 的水晶青 `#00F2FE` + 紫红渐变 `#7F00FF→#E100FF` 全片复用。

### 设计 Tokens（从 assets/logo.svg、banner.svg 提取）

| Token | 值 | 用途 |
|---|---|---|
| 背景深 | `#0A0E14` → `#151821` | 全片底色，细微网格/噪点 |
| 主强调 | `#00F2FE` 水晶青 | 命令高亮、成功状态、logo、关键数据 |
| 能量渐变 | `#7F00FF → #E100FF` | 紫红渐变，加密流、高潮段、粒子 |
| 危险 | `#FF4757` / 琥珀 `#FFB020` | 仅限痛点段与 BLOCKED 状态 |
| 正文字 | `#FFFFFF` / `#8B93A7` | 标题白、注释灰 |
| 字体 | JetBrains Mono（代码/数据）+ 思源黑体/HarmonyOS Sans（中文文案） | |

### 音乐与节奏

- BGM：100–118 BPM 暗黑电子（deep electronic / cyberpunk），强 kick、稀疏重音。
- 全片按四拍乐句分镜，转场卡在拍上；终渲交付**带 BGM 版 + 无 BGM 版**（保留 SFX）两版。
- 能量曲线：`黑场冷静(S01) → 焦躁碎切(S02) → 凝聚揭示(S03) → 稳定推进(S04–06) → 高潮爆发(S07) → 幽灵般安静(S08) → 干脆图章(S09) → 落定留白(S10)`。
- 时间码为目标时长，正式制作前做真实 BGM 节拍分析后吸附到网格。

## 三、制作路线建议

| 路线 | 说明 | 适配度 |
|---|---|---|
| **A. Remotion 代码化动效（推荐）** | 走 video-shotcraft 的「自主自由创作」管线：终端打字机、拓扑生长、粒子流、图章全部代码确定性生成（固定种子伪随机），设计 tokens 按本片 spec 蒙皮；BGM 选定后先做节拍分析再吸附时间线 | ★★★★★ 本片 90% 镜头是抽象动效+终端，正是该管线的主场 |
| B. AE 模板 | 手 K 帧复现上述镜头 | 效果可控但迭代慢，粒子/打字机批量镜头成本高 |
